# Space SHMUP (Unity 2021.3.45f2)

A vertical-scrolling space shooter built from the **Space SHMUP tutorial in Jeremy Gibson Bond's
*Introduction to Game Design, Prototyping, and Development* (Chapters 31-32)**, using the book's
*Space SHMUP Starter Kit* art (ships, weapons, shield, starfield by Peter Burroughs).

* **Unity version:** 2021.3.45f2 (LTS), 3D template / Built-in Render Pipeline
* **Controls:** Arrow keys or WASD = move, **Space** = fire, **R** = restart after Game Over

## Grading checklist -> where it lives

| Requirement | Implementation |
|---|---|
| 5 enemies (5 pts) | `Enemy` (straight down), `Enemy_1` (sine wave), `Enemy_2` (eased lerp swoop), `Enemy_3` (Bezier curve), `Enemy_4` (hovering shooter). All five are in `Main.prefabEnemies` and spawn at random. |
| Enemies damage the player (2 pts) | Ramming an enemy (`Hero.OnTriggerEnter`) costs a shield level and destroys the enemy; `Enemy_4` also fires aimed bullets that cost a shield level. Hit with no shield left = the ship explodes. |
| Shooting works (1 pt) | `Weapon` / `Projectile`: hold Space, shots travel up, hit enemies (`Enemy.OnTriggerEnter`), enemies flash red, lose health, explode and give score. |
| Scrolling starfield (1 pt) | `ScrollingBackground` on three quads (`Space.png` + two `Space_Transparent.png` layers) scrolling at different speeds, with sideways parallax following the hero. |
| Cooler in a meaningful way (1 pt) | See "Enhancements" below. |

## Enhancements ("how the game is cooler")

1. **Power-up system with 4 weapons** - dropped by destroyed enemies: Blaster (B), Spread shot (S), Phaser (P, sine-wave bullets), and a **homing Missile launcher** (M). Collecting the *same* type fills another of the hero's **5 gun slots** (placed on the `hardpoint_0..4` nodes in the hero model); collecting a different type switches weapon. A shield power-up (+) restores a shield level.
2. **Shield meter** - the kit's 5-frame shield texture shows the hero's remaining shield; it flashes red when hit.
3. **A "boss-style" Enemy_4** that enters, hovers, fires aimed shots at you, then retreats. It has more health and is worth the most points.
4. **Game feel** - additive particle explosions, camera shake on hits/kills, ship banking while you move, enemy hit-flash.
5. **Progression and HUD** - score, saved high score (PlayerPrefs), level counter (spawn rate rises every 20 s), shield bar, current weapon, Game Over screen with restart.

## Opening the project

1. In Unity Hub, **Add project from disk** and choose this folder (install 2021.3.45f2 if Hub asks).
2. On first open Unity imports everything. When it finishes, a dialog offers to **build the scene** - click *Build now*.
   (If you miss it: menu **SHMUP > Build Everything (prefabs, materials, scene)**.)
3. Open `Assets/Scenes/_Scene_0.unity` and press **Play**. In the Game view choose a portrait aspect such as 3:4 (as in the book).
4. **Commit the generated files** (`Assets/Prefabs`, `Assets/Scenes`, `Assets/Materials`, `Assets/Textures` and their `.meta` files) so the repo opens and plays with no extra steps.

The build step creates the prefabs from the kit's FBX models (scaled/rotated automatically), wires up all the script
references, and saves the scene. It is safe to run again.

## Troubleshooting

* **Ships are pink** - the kit materials need the Built-in Render Pipeline (use the plain *3D* template, not URP/HDRP).
* **Scripts show compile errors** - make sure the project is on 2021.3.x; the HUD uses IMGUI so no extra packages are needed.
* **Nothing appears after Build** - check the Console for the first error; run the builder again after it is fixed.
